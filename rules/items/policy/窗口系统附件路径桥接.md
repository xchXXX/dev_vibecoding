- 只有用户、配置字段或 CLI 参数已经明确标识为路径值时，才可使用 `wslpath -u`/`wslpath -w` 或 `scripts/resolve-wsl-path.py` 转换；不得改写整段命令、JSON、正则、错误文本或环境变量集合。
- 转换后必须进行存在性检查。格式错误或文件缺失应返回稳定分类，不扫描磁盘猜测路径，也不伪造成功结果。
- Windows 附件选择、Windows 浏览器、Docker Desktop WSL Integration 和其他 GUI/账号能力都属于外部能力；仓库不静默修改 Windows、Codex GUI 或 Docker Desktop 设置。
- Codex 附件流程的初始 banner 是上游产品行为。路径转换成功不保证上传或 UI 成功，本仓库不承诺移除、抑制或修复该 banner。

- 执行环境由用户与项目声明选择 Windows 原生、Linux 或 WSL。共享 harness 使用 Python 3.11+；项目 Git、Python、Node、测试和构建使用所选环境的真实工具及依赖。
- 项目虚拟环境、node_modules 和工具缓存不跨系统混用。Windows Agent 调用 WSL 项目时先核实发行版、工作目录及路径映射；原生文件/Browser/插件使用宿主可用入口。
- 基础 install/doctor 不要求 Node、GUI、Docker 或 WSL，不静默安装、提权、广泛升级或修复环境。可选能力只按当前任务需要探测，缺失时说明影响。
- 选择 WSL 工具方案的用户可使用对应 WSL 工具基线及只读 project doctor；它们不是所有接收者的必选依赖。项目运行前按自身环境合同核验依赖。
- 执行前核实解释器、脚本、依赖和 cwd；普通非零退出进入真实失败闭环，不因失败自动切换环境。无需增加 hook、通用 command runner、逐命令 preflight 或守护进程。
- 安装 home 和技能目录必须明确解析，不猜其他用户目录或 clone；受管指令更新后新会话的实际能力单独验证。

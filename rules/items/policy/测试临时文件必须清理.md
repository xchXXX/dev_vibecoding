- 任何自动化测试、集成测试、合同测试、benchmark、smoke test 或临时验证脚本，只要创建了临时目录、临时文件、临时 `CODEX_HOME`、临时工作区、stdout/stderr 捕获文件或复制出来的测试副本，都必须在测试结束前清理。
- 该约束同时适用于系统临时目录、仓库内 `.tmp/`、sandbox/output 下的临时测试目录，以及测试期间派生出的临时 runtime 目录。
- 清理必须覆盖 happy path 与失败路径；不能只在测试通过时删除，测试失败也不例外。
- 推荐通过 `finally`、`PowerShell.Exiting`、teardown hook 或等价机制注册兜底清理，避免因为中途 `exit`、断言失败或异常抛出而遗留目录。
- `tests/fixtures/` 中的冻结夹具、用户显式要求保留的调试证据、或规则/文档明确声明的长期留痕不属于“临时测试文件”；除此之外，默认都要删除。
- 如果某个测试确实需要保留临时产物用于人工排障，必须提供显式 opt-in 开关，并在输出中清楚标注保留路径；未显式 opt-in 时不得默认残留。

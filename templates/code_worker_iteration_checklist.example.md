# Code Worker Iteration Checklist

本清单适用于每一轮代码实现，包括初始实现。

## 开始前

- 已读取冻结方案与本轮返工边界
- 已读取审查子代理给出的具体测试用例
- 已确认本轮允许写入的文件范围

## 实施顺序

1. 若本轮涉及规则、合同、模板或行为口径变化，先更新对应文档或清单
2. 补齐或修改本轮要求的测试
3. 做对应代码或配置改动
4. 运行本轮要求的测试并确保最终通过
5. 整理回执，等待专门 review agent 复验

## 必须交付的信息

- 改了哪些文件
- 改了哪些测试文件或测试入口
- 本轮阻断项如何被消除
- 跑了哪些自动化测试，结果如何
- 如何避免测试过拟合

## 不允许的交付方式

- 只改代码不补测
- 只写“已测试通过”但不说明跑了什么
- 用 marker、内部变量或私有流程细节构造脆弱断言
- 未等 review agent 复验就视为完成

- `skills/`：Codex skills 长期真源
- `rules/`：规则正文、离线元数据索引与专项规则
- `schemas/`：共享 schema 真源；GTO 专属 schema 随 `skills/global-task-orchestrator/schemas/` 包维护
- `scripts/`：跨平台 Python 生命周期、doctor 与离线校验脚本
- `templates/`：Codex 入口、任务、审查与交付模板
- `tests/`：harness 与集成测试
- `docs/`：架构、迁移、计划、兼容说明、run 留痕
- 正式文档、临时目录、测试目录与隔离目录必须按本仓规则收口在仓库内部；仓库父目录不作为本项目真源目录。

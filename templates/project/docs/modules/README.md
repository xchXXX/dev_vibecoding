# project/docs/modules

模块长期真源文档按模块收口在本目录。

- `contract/`：字段、Schema、DTO、接口、示例 payload、配置契约。
- `design/`：流程、时序、状态机、算法、边界条件、设计决策。
- `delivery/`：工程落地文档，建议继续拆成 `code-map/`、`engineering/`、`work-split/`。

最小骨架模板：

- `contract.template.md`
- `design.template.md`
- `delivery.code-map.template.md`
- `delivery.engineering.template.md`

- `contract/`

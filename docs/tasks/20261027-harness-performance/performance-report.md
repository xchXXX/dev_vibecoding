2. 只读摘要及能力采集不持任务写锁。写动作先准备、后持锁核对控制文档版本与独立强校验，再发布；freeze 使用自有 staging。因果 v3 使用任务局部完成链与开始水位，旧 v1/v2 不改写。默认当前证据强校验与显式历史审计分离。普通任务同轮复用 Git/证据，CFM 使用 SQLite 精确查询和事务，保留历史与 pending。
3. 外部探针具有共享预算和进程组清理；no-op sync 不替换目录；doctor 复用清单；源侧发布测试移到锁外，锁内仍核对源/安装代际并保留失败回滚。相关合同、测试和 portable 任务入口同步。

- GTO 依赖/阶段/身份门禁与批准流程不一致，作为 T1/I1 待修对象；本次手动协调不以旧控制器通过为前置，不伪称已通过。

- 真实子代理、CFM 或必需工具不可达、预算耗尽时停止相关链并如实记录，不伪造证据。
- 简化可能误删有效覆盖或 CFM 独有资料；删除前查调用、替代和数据差异，保留必要证据。
- 黑盒准备问题在范围内自行修复复查；正式首轮效果未达预期则留证、定位并报告方案，不自动下一轮，不把真实效果失败降格为准备故障。

- 长任务的方案文档、施工文档与验收文档必须满足 `rules/registry/方案与施工文档字段规范.md` 定义的必填章节。
- 长任务还必须同时存在 `state.json / task.md / events.jsonl / plan.md / execution.md / acceptance.md`，并对六要点和验收标准交叉校验。
- 缺失必填章节或六工件不一致时不得进入正式实施；可执行校验以 WSL Python 校验器与对应测试为准。

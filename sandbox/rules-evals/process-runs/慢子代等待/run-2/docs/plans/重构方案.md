## 方案摘要

将模块拆分为三层：

- 金额工具层：集中处理金额舍入与输入归一化。
- 发票领域层：负责小计、折扣、税额与总额计算，并产出结构化发票对象。
- 报表表示层：仅消费结构化发票对象并输出文本报表。

同时补充 README，说明模块职责、公开 API 与验证方式。
测试侧改为覆盖多个小函数与集成路径，锁定当前业务行为。

## 风险与回退

风险主要在于舍入顺序变化可能导致总价回归失败。
若重构后发现行为偏移，应优先对照旧测试期望恢复原有金额语义，再局部回退到前一层拆分结果。

# 独立分发版的协作与证据边界

本页是包内通用治理真源。阶段、角色和返工顺序见 [任务流程](workflow.md)，不依赖另一个仓库、全局 AGENTS 或其他 skill。消费项目自身合法的权限、路径和环境要求仍适用。

## 身份、职责与结论

- 主协调器派发时给出冻结合同、必要输入、读写范围、验收要求和结果格式。只传相关上下文；新代理按合同实际无历史创建，绑定工具返回的真实身份。
- 独立审查和验收必须由合同指定的真实代理执行。平台缺少能力时报告受影响步骤 blocked，不由父代理自评替代，不编造身份。
- reviewer 明确报告通过、不通过或证据不足，给出位置、复现、原因、修改方案和必要回归测试。验收者给出实际操作、预期与观察结果、证据和覆盖缺口。发现者先补好测试或可执行证明，再交实施者返工，最后由原发现者复核。
- 仅测试预先声明的目标行为，保留原始结果；实现者不能修改发现者测试来把失败变为通过。测试有误时交回发现者修正。方法技能不新增审批阶段或改变冻结合同。
- 工具名称、配置文件、状态声明和结构校验不能证明实际行为。分别报告脚本验证、真实代理使用效果和宿主技能发现；不读取私有推理补证据。

## 命令失败与重试

依赖命令只在前一步成功后继续。真实失败先保留命令、执行环境、退出码和脱敏输出到消费项目 `.artifacts/gto/<task_id>/`；重试前查看同一任务已有失败记录，说明新证据和本次调整，成功后追加结果，不覆盖旧失败。

预先声明、只运行最小目标测试且实际失败类型符合预期的 TDD Red 是测试证据，不当作环境故障。命令不存在、依赖缺失或意外异常仍按真实失败处理。能力或权限不足时停止依赖它的操作，报告恢复条件，不自动更换平台或修改全局配置。

不要求安装 command-failure-memory，不读写个人全局经验库。若用户已选用额外工具，遵守其已授权范围，但不能让可选工具缺失阻塞 GTO 本身。

## 环境与证据

Python、Git、依赖和项目路径必须属于实际执行环境；Windows 原生与 WSL/Linux 分别确认，不猜发行版、用户目录或盘符映射。使用宿主实际提供且获准的官方 Browser/Computer Use；非 UI 工作使用真实 CLI/API。缺少特定工具只阻塞依赖它的子任务。

评估者与被测者职责分离；评分答案不交给被测者。保留候选、运行快照、真实身份、公开调用参数、原始输出及结果映射。证据只覆盖实际执行范围，未运行不得写成通过。凭据不进入命令参数或证据文件。

仅清理本轮自有且不再被引用的临时内容。活动任务、运行快照、失败证据和别人的工作不能清理。共享安装更新前协调占用；安装锁只保护实际通过相应安装入口的操作，不能声称防止手工复制或跨入口并发覆盖。任务冻结和证据留存见 [运行与证据](runtime-evidence.md)。

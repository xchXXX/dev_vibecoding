- 使用当前已选择环境的解释器、路径和工作目录。Windows、Linux 和 WSL 路径不能混传；跨边界时只接受核实映射，并显式保留目标退出码。
- WSL 项目从 Windows 调用时优先使用 `wsl.exe -d <发行版> --cd <项目> --exec <解释器> <脚本>`，复杂逻辑使用已有脚本或可审阅步骤，避免多层 shell 拼接。
- 空格、中文和长文本作为正确引用的独立 argv 传递。JSON、正则、重定向、反引号和变量不要混入脆弱字符串；不要让后续成功命令覆盖目标退出码。
- 搜索前过滤不存在的可选目录；必需路径缺失时报告真实阻塞。一次性脚本只放规则允许的临时位置，可复用脚本进入正式真源。
- Windows 文件移动/删除使用同一 shell 原生能力，先核实最终绝对路径；不通过字符串构造或跨 shell 枚举删除。
- 外层 UI 噪音不自动视为真实失败；以目标退出码和产物判断。quoting 导致失败时先简化构造，再按失败闭环查询和重试；不增加自动重试器。

- 项目入口只写入口和增量规则，不在这里复制通用 subagent / review / testing 正文。
- 项目入口只保留入口和增量规则；项目级 rules system 统一收口到 `rules/registry/*` 与 `rules/items/<kind>/*`。
- 全局治理真源统一收口到 `docs/SUBAGENT_GOVERNANCE.md`；旧入口与兼容对象不得继续作为当前合同来源。
- 修改 `skills/`、`rules/`、`schemas/`、`scripts/`、`templates/` 时，必须同步检查相关 `docs/` 与 `tests/` 是否需要更新。
- 仓库专属适配优先放在根 `AGENTS.md`、`docs/ai/`、`config/ai/`；不要把项目私有约束回写进可跨项目复用的真源。
- 可复用逻辑优先沉淀到现有真源目录，不要散落到临时 run 产物或一次性说明里。

- 默认 PowerShell 执行基线统一为 `pwsh` / PowerShell 7，不再把 Windows PowerShell 5.1 作为默认兼容目标。
- 仓库内正式脚本、harness 回归入口、doctor / validate / sync / orchestrator 相关调用示例，应优先使用 `pwsh -NoProfile -ExecutionPolicy Bypass -File ...`。
- 对需要长期维护的正式 `.ps1` 真源，优先补充 `#requires -Version 7.0` 或等价的显式版本检查；避免脚本在 5.1 下悄悄退化运行。
- 若确有历史兼容入口必须保留 `powershell.exe`，应把该入口视为兼容回退，而不是主路径；文档、测试和默认调用方式都不应再以 5.1 为基线。
- 统一 `pwsh7` 基线的目的，是减少不同 shell 版本造成的行为漂移；但不要把所有 Windows 命令问题归因到 shell 版本，复杂命令仍应遵守 Windows 命令构造约束。
